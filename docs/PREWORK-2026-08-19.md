| `200` + `application/javascript` | ⚠ **stale `index.html` referencing an old hash** | a client cache/deploy-ordering problem, not a build one |

### What pLDDT actually is, and its four limits — three already bite this project

**A second output head predicting what each residue's lDDT-Cα would be against the truth.** ⚠⚠ **The
model grading its own homework, from the same weights, in the same forward pass — not an independent
check on the first output, because it is not independent** (`A-014`).

1. ⚠ **It is LOCAL.** lDDT is superposition-free. **Every residue can score 90 while two domains sit
   in the wrong orientation.** That is PAE's job — and **`F-042` is that the census discarded it.**
2. ⚠⚠ **The calibration is population-specific and this census is off-distribution.** It was
   established on PDB-like whole proteins; **we fold sliced ECD spans with the rest of the molecule
   deliberately absent.** `F-037`: intermittent spans are ~3.5× more likely to fall below 50, cause
   unclaimed.
3. **Low pLDDT is ambiguous** — often intrinsic disorder, a RESULT not a failure. The 11 tranche-4
   rows are open for exactly this.
4. ⚠⚠ **`F-005`: the signal is partially carried by pLDDT.** So it is **not a neutral annotation on
   the result — it is entangled with it**, and judging trustworthiness with the same quantity that
   partly drives the score is two roles for one number.

### ⚠ There is no better scalar. The answer is a panel, ranked by value over cost.

**1 — Cross-check against AlphaFold DB.** Free, no GPU, covers all 3,467. ⚠ **Agreement is WEAK
evidence** — both models trained on the PDB, so `F-022` applies — **but disagreement is strong and
localises the problem.** ⚠ `ARCHITECTURE` §1 permits AFDB as an input or check, never as the
deliverable.

**2 — Experimental comparison on the few with solved ECDs** (HER2, NECTIN4, TROP2, CEACAM5).
⚠ **The only ground truth available, and it calibrates everything else** — it turns *"≥70 means
confident backbone"* from a convention into a measured statement **for this cohort at this recipe.**

**3 — Span-boundary sensitivity, which RESOLVES AN OPEN FINDING.** Refold with ±10 and ±25 residues
of flanking context. ⚠⚠ **`F-037` could not separate *fragment-out-of-context* from *genuinely
flexible*. This separates them:** confidence recovering with context means the cut did it;
confidence staying low means the region is disordered.

**4 — PAE.** Already ruled necessary; the only member that speaks to global topology.

**5 — A sequence-based disorder predictor** to discriminate the low-pLDDT band. ⚠ Another model,
