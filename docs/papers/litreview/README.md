# `litreview/` — the systematic review

**Not started.** P-001 names it as open before submission: *systematic lit review (PRISMA-grade)*,
alongside *Site4Drug and PNAS 2026 verified*.

⚠ **The protocol is written before the searching.** A search whose inclusion criteria were settled
after seeing the results is not a systematic review, and the difference is not visible in the output
— which is why the ordering is the rule and not a preference. This is the same shape as
pre-registration in [`../../D-075-pLDDT-ablation-preregistered.md`](../../D-075-pLDDT-ablation-preregistered.md);
see [`../../PREWORK-2026-08-paper-phase.md`](../../PREWORK-2026-08-paper-phase.md) for the novelty
search this feeds.

**What lands here:** the protocol · the search log (query strings, database, date, hit count — a
result count with no query behind it is not provenance) · screening decisions with reasons ·
the PRISMA counts.

**What does not:** the sources themselves. An opened source gets its own file in
[`../sources/`](../sources).
