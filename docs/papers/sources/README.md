# `sources/` — opened primary sources

**Empty.** One file per source, named for the source.

⚠ **"Opened" means read, not cited from an abstract.** P-002's recorded failure mode is the reason
this bar is written down: *one good question and four unverified protein names* — its four
trafficking examples have **no opened primary source**, and P-002 says so about itself. A source
nobody opened does not get a file here, and a file here is a claim that someone read it.

**Each file carries, per D-016:** the full citation · a resolvable identifier (DOI/PMID/URL) · the
date opened · what it is being cited *for*, stated narrowly · ⚠ **and what it does not support** —
the boundary is the part that gets lost when a source is cited a second time by someone who did not
open it.

Named and awaiting verification in P-001: **Site4Drug** · **PNAS 2026**. Named in P-002 as primary
sources for the negative class: **SURFY/PNAS** · **CSPA**.
