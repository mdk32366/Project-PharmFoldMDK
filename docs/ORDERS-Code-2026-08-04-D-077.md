## §1 — TASK 1 · Chunk-invariance (do this first; it gates Task 3)

**Why first:** it decides whether the local ceiling is a *number* (chunk 64 only) or a *curve*
(length per chunk_size). D-077 decision 2 has both readings frozen. Read them before you look at
any output.

### 1a — Tests, written and red before any probe code

`tests/test_chunk_invariance.py`

| Test | Assertion | How it bites |
|---|---|---|
| `test_comparator_detects_a_single_perturbed_coordinate` | The comparison helper reports **not-identical** when one CA coordinate differs in the last decimal place | Feed it two structures differing by one atom. **If this passes on identical-only inputs it is not biting** — it must red against a comparator that rounds. |
| `test_comparator_detects_a_plddt_difference_with_identical_coordinates` | Not-identical when coordinates match and pLDDT does not | Guards a comparator that only reads coordinates |
| `test_comparator_is_exact_not_tolerant` | Any `atol`/`rtol`/`round()` in the comparison path fails the test | D-077 dec 2 forbids an invented tolerance |

**These are pure-logic tests. They run on the CI gate. No GPU.**

### 1b — The comparison helper

Write `worker/fold_compare.py` — a pure function taking two `(coords, plddt)` pairs and returning an
exact-equality verdict plus, when unequal, **where** they first diverge (residue index, field). No
tolerance. No rounding. It reports; it does not judge.

### 1c — The run (Owner-authorised, local box, ~minutes)

Fold **one fixed sequence, short enough that every chunk_size fits** — Trop-2 (~248 aa) is the
existing precedent (~93 clean folds, `ARCHITECTURE.md:598-599`) — at `dtype=int8`, at
**chunk_size 64, then 32, then 16**, three folds total. Write each output to `data/derived/`.

**Then compare, and read against D-077 decision 2's frozen table — only against it.**

- Byte-identical across all three → `chunk_size` is a memory/time knob. **Task 3 is unlocked.**
- Any difference at all → `chunk_size` is a recipe dimension. **Task 3 is abandoned, not deferred.**
  Land the divergence as its own F-entry — *ESMFold's chunked trunk is not output-invariant* is a
  reportable methods finding, and the first-divergence location is the evidence.

**Do not invent a third reading. Do not compute a "close enough" margin.**

`dtype=int8, chunk_size=64`, k=4, step=8, resuming from the JSONL as designed.

- Bounds and recipe stated in the log line before the first fold.
- **Expect a small number.** `ARCHITECTURE.md:616` records 378 MiB of headroom at 440 aa against

  real targets. **Do not read a small ceiling as a failed measurement** — it is a measurement.

`chunk_size 32`, then `16`. If Task 1 returned *differ*, **Arm B does not run** and the file says so.

**Recording:** each arm's result is its own F-entry citing D-077, stating the recipe triple, the
JSONL path, the k-rule, and the band. **No silent update of `CEILING_KNOWN_GOOD`** — the constant
moves in the same PR as the F-entry that measured it, or not at all.
