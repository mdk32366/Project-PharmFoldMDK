### D-055 — A glossary, and a contract test that reddens when an undefined term reaches the screen

- **Date:** 2026-07-26
- **Status:** Proposed → Accepted on merge.
- **Relates:** D-051 (the narrative surfaces this makes legible), D-016 (a claim names how it is
  known — a term nobody can decode is a claim nobody can check), D-024 (the honest denominator,
  which is unreadable if the reader cannot parse its units), D-053 decision 5 (which kind of number
  may be a literal).
- **Amends:** nothing. Additive.

**Context.** The UI currently puts **pLDDT, PAE, ESMFold, ECD, ADC, quasi H-score, TCGA, IHC** and
`int8` in front of a reader, mostly undefined. pLDDT carries the entire honesty argument — the
confidence layer, the band boundaries, the careful rendering of PTPRZ1 at 30.68 — and nothing on
screen says what it is. **A reader who cannot decode the term cannot evaluate the honesty built on
it**, which means the project's strongest work is currently unreadable by the person assessing it.

**Decision 1 — two registers, split by domain and not by document.**

- **Biology, oncology, chemistry → plain language, roughly an eighth-grade reading level.** The
  reader has no background here and every unexplained term is a wall.
- **Machine learning and statistics → peer level, unchanged.** He teaches this. Simplifying
  "λ selected by nested cross-validation inside each leave-one-out fold" would lose the claim and
  patronise the reader in one move.
- **pLDDT sits on the boundary and gets both:** the precise form (*per-residue predicted
  confidence*) and the plain one (*the model's own score for how sure it is about each piece*).

**⚠ Stated so the green test is not over-read (D-016): this register split is a human judgement.
No test enforces it.** The contract test in decision 3 checks that terms are *defined*, and the
tripwire in D-056 checks that sentences are *short and plain*. **Neither checks that the right
register was chosen.** That remains review.

**Decision 2 — the glossary is `ui/src/glossary.js`, and its definitions are literals.** Each entry
carries `term`, `expansion` (what the letters stand for), and `plain` (one sentence, no jargon).
Applying D-053 decision 5's test — *would this change if our data changed?* — a definition would
not. It is a definition, not a statistic, so it is correctly a literal and does not need a route.

**Decision 3 — the contract test: an undefined term on screen reddens the gate.** The glossary's
failure mode is drifting behind the interface — someone adds a term, nobody adds an entry, and it
rots silently. So it is pinned the way the architecture diagram was pinned this morning: a test
renders every component through the D-046 harness, scans the visible text for acronym-shaped
tokens, and **fails if any token lacks a glossary entry.**

Exemptions are **derived, not typed**: the 82 gene symbols come from `data/cohort_82.txt` — the
cohort of record — plus a small allowlist for interface words (`API`, `UI`, `PDB`, `CSV`). A
hand-typed exemption list would be the same rot in a different file.

- **Deep-learning justification:** pLDDT is the network's own uncertainty, and this project's whole
  argument is that it renders that uncertainty honestly rather than averaging it away. **An honest
  rendering of a term the reader cannot decode is not honest in any sense that matters.** This is
  the last step of making the model's own output legible to the person judging it.
- **Consequences:** `ui/src/glossary.js`, `Term.jsx`, a glossary block on `/method`, inline `<Term>`
  usage, and `Glossary.test.jsx` / `Term.test.jsx` / the contract test. No new dependency, no route,
  no change to any supplier.

### D-056 — The plain-language pass, and a readability tripwire calibrated to what we actually wrote

- **Date:** 2026-07-26
- **Status:** Proposed → Accepted on merge.
- **Relates:** D-055 (the register rule this executes), D-049 (pin to observed values, not
  aspirations), D-051 Constraint A (which this pass is the single most likely thing to break).
- **Depends on:** D-055 merged — the copy references terms that must already exist.

**Context.** D-055 defines the terms. The surrounding sentences are still written at postgraduate
level in places — e.g. *"where a disagreement is explicable by known homology (convergent folds,
divergent sequences within a family)"* — which no glossary entry rescues, because the problem is the
sentence, not the word.

**Decision 1 — rewrite the domain copy; leave the ML copy alone.** D-055's register rule, executed
across every component that renders prose. Meaning is preserved exactly; only the reading level
moves. **Nothing that is currently precise becomes vague.** A shorter sentence that says less is a
failure of this pass, not a success of it.

**Decision 2 — a readability tripwire, with its ceiling set after the fact.** Flesch–Kincaid grade
level is computed over rendered text, with numerals stripped and glossary terms and gene symbols
exempted from the syllable count. **The ceiling is calibrated from the measured value once the
rewrite is done, plus a small margin** — the D-049 pattern: pin to what is observably true, not to
a number we would like to be true.

**⚠ What this test is and is not.** Flesch–Kincaid counts syllables and sentence lengths. **It does
not measure comprehension**, it is trivially gameable by chopping sentences, and it penalises terms
that cannot be avoided. It is therefore a **regression tripwire** — it catches copy drifting back
toward density — and it is **not evidence that the writing is clear.** That claim is made by a human
reading it, and this entry does not let a green test stand in for one.

- **Deep-learning justification:** none directly, and stated rather than manufactured. This pass
  makes the deep-learning claims *readable by the reader who has to assess them*. That is its whole
  value and it does not need a bigger one.
- **Consequences:** copy edits across `Story`, `MethodNote`, `AdcContext`, `CoverageView`,
  `TargetView`, `CoverageLine`, `Provenance`, `PlddtSpread`, `CancerAssociations`; one new test.

## 1. ⚠ Four things that will bite

**(a) This pass is the most dangerous moment for Constraint A since it was written.** Rewriting
prose is exactly when a hand types *"all 82 targets"* or *"a maximum of 84.23"* into a sentence.
D-051's and D-053's absence tests exist for this and will be exercised for real tonight. **If either
goes red, that is the system working — fix the copy, never the test.** Report it if it happens; it
is a live proof of the same class as this morning's contract test.

**(b) Do not simplify the ML copy.** The register rule is directional. If a sentence about
regularization, leakage, or leave-one-out gets shorter and vaguer, that is a regression.

**(c) `<Term>` must not be hover-only.** Hover does not exist on touch and is invisible to a
keyboard. The definition must be reachable by focus and by tap. This gets a test.

**(d) The contract test's token regex will false-positive before it works.** Gene symbols look
exactly like acronyms — that is what the `cohort_82.txt`-derived exemption is for. Cancer names,
units, and ordinary capitalised words may also trip it. **Do not loosen the regex until the test
passes.** Tighten the *exemption source* if it is principled, or propose the fallback (a curated
watchlist of must-define terms) and say so — but a contract test that passes because it stopped
looking is worse than none, and that is the same stop condition as this morning.
