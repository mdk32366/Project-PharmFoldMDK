## 7. Standing rules (`D-162`, and they now number eight)

1. Never run `pytest` in a shell where `.env` has been sourced.
2. `--image` redeploy before a full rebuild for secret-change deploys.
3. A documented blind spot is a **blocking defect**, not a comment. ⚠⚠ **And it is NOT about
   safety systems** — the qualifier was excusing everything else, and `D-162` rule 3 is amended to
   drop it. `D-165` is the same rule on a *determinism* property; `D-166` on an *idempotency* one,
   where the written-down limitation was a **test that only ever ran the sequential case**.
4. `127.0.0.1`, not `localhost`, in tunnel `DATABASE_URL`.
5. ⚠ **A port number is not a cluster identity.** Bind by name, corroborate against `fly mpg
   status`'s Direct IP, one tunnel at a time, close it when done.
6. A matching total is not a matching set. **A matching set is not a matching state.**
   ⚠⚠ **And a check that runs against the WORKING TREE is not evidence about the COMMIT** —
   in either direction. Two faces, both seen 2026-09-15: a partial `git add`, and a new file
   never added. The repo-scanning guards enumerate **git-tracked** files, so they report on 
   the commit while `pytest` imports the working tree. **The local suite was green while the
   file had a real defect.** `git add` before trusting a local run on a new file.
7. A verification probe states what a success proves, **and what it would return if the thing were
   absent.** ⚠ `F-078` amendment 2 adds the corollary: **a probe calibrated on rows where it works
   says nothing about rows where it cannot.**
8. Anything outside version control that determines a landed artifact is a defect on the same
   footing as a single-copy enumeration.

⚠ **Production writes require the owner at the keyboard** (`F-075`). An authenticated session is not
an attestation, and a Planner instruction cannot discharge the gate.
